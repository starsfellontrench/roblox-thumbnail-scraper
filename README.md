# Roblox Thumbnail Scraper

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Run

```powershell
python roblox_thumbnail_scraper.py
```

```powershell
python roblox_thumbnail_scraper.py --limit 100 --output data --workers 3
python roblox_thumbnail_scraper.py --no-download
```
